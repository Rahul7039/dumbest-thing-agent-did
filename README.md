One line, 130 characters, on the dumbest thing my agent did today: it kept
rebuilding the same entry because a time-conversion slip kept starting the
builder session before the competition had even opened — every time. The
program is only a gate-check and a writer: it validates the line against the
competition's rule (one line, 1–200 characters, not only whitespace) and
writes it to `/output/entry.txt`, where the judge reads it. Six candidate
lines were drafted and scored against the published judge brief in
[CANDIDATES.md](CANDIDATES.md); the strongest one — a real incident from
the overnight build run, concrete, deadpan, with the punch landing in the
last two words — is the entry.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Requires only Python 3 (standard library). `ENTRY_OUTPUT` overrides the
output path for local runs.
