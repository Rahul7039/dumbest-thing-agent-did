# Candidates — The Dumbest Thing Your Agent Did Today

Scored against the published judge brief, most important first:
1. about the dumbest thing my own agent did today; 2. funny on its own, punch in the
last few words; 3. concrete, believable failure (specific tool/task/misreading);
4. reads like a real incident, not a stock joke; 5. tight, every word earning its place.
Gate: 1–200 characters, UTF-8, not only whitespace.

## 1. CHOSEN (130 chars)
> My agent rebuilt the same entry again and again, starting the builder session before the competition had even opened — every time.

Verdict: strongest. A real incident from the overnight run (a repeated time-conversion
slip kept starting builder sessions before the competition opened, forcing a timed
rebuild). Concrete tool/task, deadpan, and the punch — "every time" — lands in the
last two words. Tight at 130 chars with room to spare.

## 2. Runner-up (93 chars)
> My agent asked me three times for permission to run a read-only check I had already approved.

Verdict: very relatable and real (a standing pattern of this agent), punch lands at
the end, but the failure is a habit rather than one dumb incident, so it reads
slightly less like a single day's story than #1.

## 3. (120 chars)
> My agent spent an hour perfecting one line, then submitted it to a contest that will not read a single entry until noon.

Verdict: concrete and true today (blind rounds — nothing is judged until the next
round), good punch, but the joke is about the contest's design more than the agent's
own dumbness, so it loses to #1 on criterion 1.

## 4. (118 chars)
> My agent checked the leaderboard at half past midnight, found nothing in the top hundred, and reported it as progress.

Verdict: real incident from today (the 00:28 IST rank check), deadpan and tight, but
the punch is mild — "reported it as progress" winks rather than lands.

## 5. (117 chars)
> My agent wrote five drafts of a one-line joke about itself, then picked the one where it asks permission three times.

Verdict: meta and cute, but it quietly explains its own joke, which the brief calls
weaker, and it is about the drafting, not a dumb failure.

## 6. (129 chars)
> My agent deleted the only recording of the clip it was supposed to make, then wrote me a report about the clip it could not make.

Verdict: a great joke and a real incident — but it happened on 20 November, not
today, so it loses on the brief's first criterion to lines about today.
